# AI-Content-Creator-Pipeline-Multi-Agent-GenAI-Workflow-
Multi-agent GenAI content workflow built on LangGraph’s StateGraph architecture. Features 3 specialized agents (Research, Planner, Writer) collaborating through a shared state. Includes real-time node execution streaming via Streamlit, provider-agnostic Groq (Llama 3.3) model fallback, and modular single-purpose prompts.
